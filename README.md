# AgentSwitch

终端里的 **Codex / Claude Code 中转切换器 + 用量统计**：一键切换中转站，并按 models.dev 的价格把本地用量折算成等值美元。

> 单个 C++20 可执行文件，基于 [FTXUI](https://github.com/ArthurSonzogni/FTXUI) 和 [DuckDB](https://duckdb.org)，数据全部留在本机。

## 特性

- **切换中转**
  - Claude Code：改写 `~/.claude/settings.json` 的 `env.ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN`，其余设置原样保留。
  - Codex：直接读取 `~/.codex/config.toml` 里的 `[model_providers.*]`，切换时只改顶层 `model_provider` 一行，注释和格式不动。
  - 支持添加、编辑、删除中转；写入前自动备份，原子替换。
- **用量统计**
  - 解析 Claude Code 和 Codex 的本地会话日志，只统计 token 总量，不区分中转站。
  - 全部 / Claude / Codex 三个标签，每个标签下有今日、本周、本月、总计四个周期。
  - 输入、输出、缓存读、缓存写分别用不同颜色表示。
  - 回车或点击任意一行，查看它从第一次使用至今的每日用量，可按日、周、月汇总。
- **等值美元**：价格取自 [models.dev](https://models.dev)（只拉 anthropic 和 openai），查询时按最新价格实时计算。
- **增量扫描**：按文件游标只读新增内容，事件按稳定 key 去重，重复扫描不会重复计数。
- 键盘和鼠标都能操作。

## 安装

需要：

- Linux x86_64
- [xmake](https://xmake.io)
- clang（支持 C++20）
- libcurl 开发头文件（Debian / Ubuntu：`sudo apt install libcurl4-openssl-dev`）

```bash
git clone https://github.com/koarz/agentswitch.git
cd agentswitch
xmake            # 首次构建会下载 FTXUI、nlohmann_json 和预编译的 libduckdb（约 40 MB）
xmake run
```

构建产物是 `build/linux/x86_64/release/agentswitch`，旁边还有 `libduckdb.so`（可执行文件通过 `$ORIGIN` 找到它）。想把它装到别处，请把两个文件放在同一目录。

## 使用

直接运行 `agentswitch` 进入 TUI。

| 页面 | 按键 | 作用 |
|---|---|---|
| 全局 | `1` / `2` | 切换 / 用量 页面 |
| 全局 | `r` | 重新拉取价格并扫描日志 |
| 全局 | `q` | 退出 |
| 切换 | `↑` `↓` | 选择条目 |
| 切换 | `Tab` / `←` `→` | 在 Claude 和 Codex 两栏之间移动 |
| 切换 | `Enter` | 切换到选中的中转 |
| 切换 | `a` / `e` / `d` | 添加 / 编辑 / 删除（删除需再按一次确认） |
| 切换 | `i` | 把当前外部配置保存为一个条目（仅 Claude） |
| 用量 | `Tab` / `Shift+Tab` | 切换 全部 / Claude / Codex |
| 用量 | `←` `→` | 切换周期 |
| 用量 | `↑` `↓` `PgUp` `PgDn` | 选择模型 |
| 用量 | `Enter` | 打开所选行的每日用量 |
| 每日用量 | `↑` `↓` `PgUp` `PgDn` | 滚动 |
| 每日用量 | `d` / `w` / `m` | 按日 / 周 / 月 |
| 每日用量 | `Esc` | 返回 |

鼠标可以点击标签、周期卡片和模型行，滚轮用来滚动。

也可以不进 TUI：

```bash
agentswitch report                       # 同步日志并打印用量报告
agentswitch scan                         # 只同步日志
agentswitch prices                       # 强制刷新 models.dev 价格
agentswitch snapshot usage 120x40 0 2    # 把页面渲染成文本（调试用）
```

## 工作原理

### 切换

| 工具 | 中转列表来源 | 切换时改动 |
|---|---|---|
| Claude Code | `~/.config/agentswitch/profiles.json` | `~/.claude/settings.json` 的 `env.ANTHROPIC_BASE_URL`、`env.ANTHROPIC_AUTH_TOKEN` |
| Codex | `~/.codex/config.toml` 的 `[model_providers.*]` | 顶层 `model_provider` |

选择「官方登录」（Claude）或「OpenAI 默认」（Codex）会移除覆盖。每次改写前会在原文件旁边保存一份 `*.agentswitch.bak`。已经运行中的会话不受影响，新会话才会使用新的中转。

### 统计

- **Claude Code**：读取 `~/.claude/projects/**/*.jsonl` 中 assistant 消息的 `message.usage`，按 `message.id + requestId` 去重，同一响应多次写入时取各字段最大值。
- **Codex**：读取 `~/.codex/sessions/**/*.jsonl` 中的 `token_count` 事件，用 `last_token_usage` 作为单次请求的增量，连续相同的累计值只算一次；`input_tokens` 里已包含缓存部分，会拆成新输入、缓存读、缓存写分别计价。
- **周期**：使用本地时区，一周从周一开始。
- **价格**：`费用 = (输入 × 输入价 + 输出 × 输出价 + 缓存读 × 缓存读价 + 缓存写 × 缓存写价) / 100 万`。模型名会做容错匹配（日期后缀、`-latest`、`4.5` 与 `4-5`、`provider/` 前缀、最长前缀）；匹配不上的模型只统计 token，在界面里标 ⚠，不会按 $0 静默计入。

### 数据位置

| 路径 | 内容 |
|---|---|
| `~/.local/share/agentswitch/usage.duckdb` | 用量事件、价格缓存、文件游标 |
| `~/.config/agentswitch/profiles.json` | Claude 中转列表（明文，权限 0600） |

遵循 `XDG_DATA_HOME`、`XDG_CONFIG_HOME`、`CLAUDE_CONFIG_DIR` 和 `CODEX_HOME`。

## 注意

- 美元是**估算值**：Claude 的 1 小时缓存写入按 models.dev 的 `cache_write` 计价，超长上下文的分档价格没有处理，中转站自己的倍率更不在内。
- Claude 的切换依赖 Claude Code 对 `settings.json` 中 `env` 的处理；如果你在 shell 里也导出了 `ANTHROPIC_*`，请确认实际生效的是哪一个。
- DuckDB 同一时间只允许一个进程写入，TUI 运行时再执行 `report` 等命令会提示数据库被占用。
- 目前只在 Linux x86_64 上测试；其他平台需要调整 `xmake.lua` 里的 `duckdb-bin` 包定义。
- 中转的 token 以明文保存在本机配置里，与 Codex、Claude Code 自身的做法一致。

## 隐私

- 只读取本机的会话日志，不上传任何内容。
- 唯一的网络请求是从 `https://models.dev/api.json` 下载价格。

## 项目结构

| 文件 | 作用 |
|---|---|
| `src/main.cpp` | 命令行入口 |
| `src/ui.cpp` | TUI（切换页、用量页、每日用量、表单） |
| `src/switcher.cpp` | Claude / Codex 配置的读取与改写 |
| `src/scanner.cpp` | 增量解析 Claude 和 Codex 会话日志 |
| `src/store.cpp` | DuckDB 存储 |
| `src/pricing.cpp` | models.dev 价格拉取与模型名匹配 |
| `src/report.cpp` | 按周期汇总并计价 |
| `src/worker.cpp` | 后台线程：刷新价格、扫描日志、生成报告 |
